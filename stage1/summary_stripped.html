03 / Structure and Data Processing

Local All_Diets.csv→Pandas cleaning→Statistics / NumPy clustering→Azure Functions JSON

Cleaning rules

  • Strip whitespace from column names and text; normalise diet and cuisine casing.
  • Missing categories become unknown; a missing recipe name becomes Unnamed recipe.
  • Invalid, missing, negative and infinite nutrient values are filled with the column's valid mean.
  • Empty data, a missing required column, or a column with no valid value at all is rejected.

04 / API Contract and Front-End Hand-Off

Base URL: http://localhost:7071/api. Every endpoint returns JSON, and each data endpoint reports its execution time, source and cache state.

GET routeInputMain output and purpose
/healthnoneService status; touches no data, so it works as a liveness check.
/insightsnoneaverage_macros → bar chart; summary.diet_counts → pie chart; correlation → heatmap.
/recipesdiet_type, search, page, limitRecipe rows plus paging fields. search matches recipe name, diet type and cuisine, and combines with the filter.
/clustersk, default 3, range 1–10points, centroids, cluster_counts → scatter chart coloured by cluster.

Paging defaults to 50 rows and is capped at 500; pages are 1-based and a page past the end returns the last page. Invalid parameters return 400 and an unknown diet type returns 404. A search with no match returns an empty list. Internal errors return a generic error JSON.

The existing frontend/ still targets the earlier three-endpoint version; the new controls and charts are Person 2's work. The CORS template allows localhost:5500 and 127.0.0.1:5500.

NumPy k-means

Protein, carbohydrate and fat are the three features. They are z-score standardized first so that no unit scale dominates the distance. The random seed is fixed at 42 and the centroids start from distinct sample vectors; the loop then alternates nearest-centroid assignment and cluster-mean updates for at most 100 iterations. A constant feature uses a scale of 1, and an empty cluster keeps its previous centroid, so no NaN can appear.

Measured grouping at k = 3: cluster 0 holds 1,205 recipes, cluster 1 holds 5,681 and cluster 2 holds 920. The returned points and centroids are converted back to grams, while inertia stays as the sum of squared distances in the standardized space.

Cluster numbers carry no dietary meaning. This is exploratory grouping, and a single initialisation is not guaranteed to be globally optimal. Undefined values in the correlation matrix are encoded as null.
